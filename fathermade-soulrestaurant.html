영혼식당 · 신규 개발

기간 2026.01 ~ 2026.12
역할 클라이언트 프로그래머
기술 Unity, C#

냥킹덤의 주요 코드, 유틸리티 기능, 프로젝트 폴더 구조 등 주요 부분을 기반으로 대부분의 코드 및 구조를 재구성하고 개선하여 시작한 신규 프로젝트입니다. 머지게임(가십하버)를 레퍼런스로 잡고 단일로 먼저 시작했습니다.

프로젝트 초기 아키텍처 설계

Addressable Asset System, Universal Render Pipeline, New Input System을 프로젝트에 적용했습니다.

Addressable 도입

  • 냥킹덤에서 사용되던 클래스 이름, 함수 시그니처를 유지하여 다른 팀원들의 작업 합류에 무리가 없도록 주의
  • 에셋을 자동으로 관리될 영역과 수동으로 관리될 영역으로 분리
  • 에따른 프로젝트 구조 제시 및 적용

URP 적용

  • UI Canvas, Camera 관리 방식 수정
  • Post Processing 적용 방식 수정

New Input System

  • 여러 플랫폼, 여러 인풋 디바이스에서의 입력 처리

보드 생성 파이프라인 자동화

Photoshop script, PSD Importer, 2D TileMap 기능을 활용해 게임의 메인 로직인 보드판 생성 기반을 마련했습니다.

설계 요구사항

  • 여러 이미지를 하나의 파일에 Sprite Sheet 방식으로 관리하는 부담 제거 및 외주 작업자와의 편의성 고려하여 각 아이콘 이미지 파일은 단일 포토샵 파일로 유지
  • 포토샵 특수효과가 사라지지 않고 잘 적용될 수 있도록
  • 과도한 용량 중복을 피해 커밋을 가볍게 유지
  • 출시 이후 편리하게 아이템 아이콘을 추가 및 수정하면서도 이 과정에서 서비스 안정성을 해치지 않도록
  • 각 아이템 및 슬롯을 이용해 보드판을 새로 생성하거나 수정하는 과정이 편리해지도록

구현 프로세스

  1. 아이콘 리소스 작업 - 알맞은 폴더 내에 알맞은 이름으로 파일 배치
  2. Photoshop script를 통해 프로젝트 구조 내의 상대경로에서 아이콘을 긁어와 Linked로 파일을 레이어 재생성
  3. PSD Importer를 통해 Sprite Atlas 및 TileMap Asset 자동 생성
  4. 에디터 스크립트를 통해 각 아이콘의 Address 세팅

3D 공간 내 2D 오브젝트 정렬 에디팅 툴

아웃 게임 요소인 식당을 개발하기 위해 3D 공간에 2D 이미지를 적절한 정렬순서를 유지하며 배치할 수 있는 에디팅 툴을 구현했습니다.

엔진에서 Sorting Layer, Sorting Order, Sorting Group 등 다양한 옵션 및 기능을 제공하지만, 아트 및 기획자분들의 작업 효율 및 휴먼에러를 줄이기 위해 보면서 보이는 대로 배치하면 보이는 순서대로 렌더링될 수 있도록 텍스쳐를 자르고 배치하는 툴을 제작했습니다.

작업 프로세스

  • 해당 텍스쳐 우클릭 메뉴를 통해 에디터 스크립트 실행하여 이미지 Multi mode sprite로 자르기
  • Sprite Editor의 확장 툴에서 바닥에 해당하는 pivot 설정
  • Scene View에서 Handle을 통한 이미지 배치

성능 최적화

애니메이션 성능

  • DOTween 패키지 도입하여 연출 성능 향상

UI Canvas 최적화

  • UI 요소에 사용되는 Animator 지양
  • 필요한 경우 독립 캔버스로 분리하는 등 UI 기능 최적화

SDK 업그레이드 및 분석 체계 구축

변경된 Unity 버전에 맞게 각종 SDK를 업그레이드하고 초기화 과정 및 시점을 다듬었습니다.

적용 SDK

  • NHN GameBase
  • Firebase
  • AppsFlyer
  • Google AdMob

Firebase Analytics 개선

  • Firebase Analytics 지표 수집 방식 개선
  • 팀원들이 볼 수 있도록 GA 보고서 세팅
