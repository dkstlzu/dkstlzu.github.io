냥킹덤 · 라이브 서비스

기간 2024.09 ~ 2025.12
역할 클라이언트 프로그래머
기술 Unity, C#

국내 출시 직후에 합류한 프로젝트로 기존 시스템 파악 및 최대한 기존 작업 스타일을 해치지 않는 선에서 개발을 이어 나가는 데에 집중했습니다. 라이브 개발팀에서 일어날 수 있는 사건·사고들을 팀 내에서 경험하면서 경각심을 갖게 되고 안정적인 운영 서비스의 중요도를 알게 된 프로젝트입니다.

메인 콘텐츠 제작

  • 기존 전투 및 게임 시스템을 확장하여 일반 스토리 전투와 다른 보스레이드(토이레이드), 인트로 전투, 다수 파티아레나(마스터아레나)를 개발
  • 신규 소속 진영 스텔라 구현
  • 신규 지역 및 관련 시설, AI 등 구현
  • 신규 등급 장비 초월 장비 구현
  • 글로벌 채팅 시스템을 확장하여 개인 메시징 시스템 제안 및 구축

게임 최적화

리소스 최적화

  • 텍스처 리소스 메모리 120MB → 70MB 감소 (리소스 해제 시점 및 중복 사용 점검)
  • 다국어 에셋이 메모리에서 내려가지 않는 현상 개선

렌더링 최적화

  • 화면 밖 콘텐츠의 업데이트 최소화
  • 프레임 드랍이 확인되는 UI를 검수하고 최적화 진행
  • 아이콘 풀링 및 풀링 방식의 스크롤을 적용하여 UI 개수 간소화

서브 콘텐츠 제작

  • 리텐션 확보를 위한 마을 상호작용 콘텐츠 제작
  • 부르마블, 사과 미니게임, 수박 미니게임 등 약 10종의 이벤트 제작
  • 친구 초대 이벤트 구현
  • BM 개선을 위해 수십 종의 패키지 상품 등을 구현

UI 구조 개선

  • UI/UX 개선 작업 및 이벤트 UI들의 온디맨드 리소스 로드 적용
  • 프로필 다중 슬롯 및 편집, 업로드 기능 제안 및 구현

글로벌 스토어 API 관련 툴 제작

글로벌 출시에 따라 각 스토어의 인앱 상품 데이터 관리가 필요했습니다. 팀 내 테이블과 API 데이터 간의 변환 및 호환을 위해 Visual Basic으로 관련 툴을 제작했습니다.

  • 주요 대상 오픈 국가: 일본, 미국, 대만, 유럽
  • 추가 지역: 동남아, 아랍 문화권 국가
  • Google Play Store, App Store API 자동 데이터 관리

커뮤니티 관리 및 유저 대응

  • 공식 디스코드 커뮤니티 기본 관리
  • 공식 문의 메일 관리
  • 버그 보고에 따른 유저 대응 및 해결
