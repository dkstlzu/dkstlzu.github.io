Period 2024.09 ~ 2025.12
Role Client Programmer
Tech Unity, C#, Visual Basic
Store App Store · Google Play

A live-service project I joined right after the Korean launch and stayed on through the global launch. My main job was to first understand a codebase already in service, then build new content and systems on top of it without breaking the existing structure or the team's working style.

Going through real incidents alongside the live team taught me firsthand that keeping a service stable matters as much as shipping new features quickly.

Optimization

In a live environment where content keeps piling up, I audited resource usage and UI load.

Memory

  • Audited resource release timing and duplicate usage, reducing average texture memory from 120MB → 70MB (about 40% less)
  • Optimized the memory of the localized string container, about 28MB → 20MB (8MB saved)
  • Fixed localized assets not being unloaded from memory

Runtime · UI

  • Minimized updates for off-screen content
  • Removed logic that caused GC allocations
  • Reviewed UIs with confirmed frame drops and applied icon pooling and pooled scrolling to reduce the number of UI objects

In-house Tool Development

In-app Product Management Tool

Problem

The global launch greatly increased the number of in-app products per country and store, but product information such as prices was still being entered manually into the store consoles

Solution

Built a Visual Basic tool that pulls store product data via the Google Play · App Store APIs, compares and validates it against the internal product table, and sets mismatched items in bulk through code
