기간 2023.01 (1개월)
역할 프로그래머 인턴
기술 Unreal Engine 5, C++, Blueprint, Vivox

이전에 구현해 본 적이 있던 Vivox API를 활용해, Unreal Engine 5에서 사용할 수 있는 Vivox Plugin 기반으로 음성 채팅 기능을 구현했습니다. C++로 기능을 구현하고 Blueprint에서도 사용할 수 있도록 확장했습니다.

음성 채팅 기능 구현

  • Volumetric Trigger를 통해 공간에 PC가 접근하면 공개 음성 채팅 채널에 자동 입장·퇴장
  • 상호작용 키로 입장하며 제한 인원수가 정해진 Private 채널 구현
  • 유저별 볼륨 조절 및 음소거 기능 구현
  • C++ 구현부를 Blueprint에서 사용 가능하도록 확장
